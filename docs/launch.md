# Запуск на macOS и Windows

Скрипты запуска **ничего не скачивают и не устанавливают**. Если зависимостей не
хватает, они выводят сообщение в терминале. Установите зависимости сами и повторите
запуск. Linux не поддерживается.

## Что установить один раз

- **macOS:** Apple Silicon, macOS 14+; Python **3.11** для arm64;
  Apple Command Line Tools (команда `xcode-select --install`, нужны для сборки `diffq`).
- **Windows:** x86-64, Python **3.11 x64**. Для сборки `diffq` могут понадобиться
  Microsoft C++ Build Tools с компонентом «Desktop development with C++» и Windows SDK.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) — для установки
  зафиксированных Python-пакетов из `uv.lock`.
- [FFmpeg](https://ffmpeg.org/download.html) с **ffprobe** и MP3-энкодером
  **libmp3lame**. Оба исполняемых файла должны быть доступны в `PATH`.
  На macOS с уже установленным Homebrew: `brew install ffmpeg`.
  На Windows распакуйте сборку FFmpeg и добавьте её каталог `bin` в пользовательский `PATH`.
  После изменения `PATH` откройте новый терминал; при запуске из Finder на macOS
  окружение Terminal должно видеть FFmpeg.

В терминале в папке проекта выполните вручную:

```sh
uv sync --frozen --python 3.11 --no-python-downloads
```

Эта команда создаёт `.venv` и устанавливает зависимости приложения: PySide6,
audio-separator, CPU PyTorch, NumPy, SoundFile, psutil и их зависимости.
Системный Python не изменяется. Установка требует интернета; скачивание Python
этой командой отключено — Python 3.11 нужно установить заранее.

## Обычный запуск

- macOS: двойной щелчок по **`Start.command`**.
- Windows: двойной щелчок по **`Start.cmd`**.

Активация окружения не нужна. Оба файла используют только `.venv` в папке проекта,
проверяют зависимости и открывают GUI. Модели хранятся в `models/`, результаты —
в `outputs/`. Старые окружения в `.runtime/` больше не используются; эта папка
может содержать файл блокировки запущенного приложения.

Проверка без открытия GUI: запустите `Start.command --check` (macOS) или
`Start.cmd --check` (Windows) из терминала. Проверяются наличие основных
Python-модулей, запуск FFmpeg/FFprobe и наличие libmp3lame, без загрузки моделей.

Веса моделей по-прежнему скачиваются **по нажатию «Подготовить модели»** в GUI.
Это отдельное действие, не автоматическая установка зависимостей при запуске.

Проверено на текущем Mac Apple Silicon. Запуск на настоящей Windows-машине пока
не проверен; наличие Windows-кода и тестов не заменяет такой проверки.
